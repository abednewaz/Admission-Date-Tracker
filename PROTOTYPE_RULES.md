# Exact Static Prototype Contract

This branch is a visual model of the Admission Tracker, not a simplified mockup.

## Non-negotiable
- Preserve every existing visual component, card, button, logo, text, popup/modal, section, information field, and feature representation.
- Redesign presentation only; do not remove information because a feature is non-functional in the prototype.
- Notice Board content remains updateable.
- Ratings/reviews do not persist.
- Mark/target state does not persist.
- Daily reminders do not run.
- Backend/account/persistence-heavy functions are disabled unless needed to render current notice data.
- Every component must remain visually complete even when its real action is disabled.
- Preserve creator, ratings, reviews, requirements, official links, university data, logos, filters, Grid/List, User Manual, Student Tools, Board Result, PCM ranking, Calendar, Notice Board, Mark Your Target, footer, and all added controls.
- Separate visual pages remain represented: Dashboard (/), Universities (/universities), Tools (/tools), About (/about).
- Notification control is visually above the search bar on the dashboard.
- Tools are not a dashboard content block; they remain represented on /tools.
- No 'BD University Admission' kicker.
- Hero slogan is 'Every University. Every Deadline. One Place.'
- Use the approved BUET + DU + Medical banner artwork.
- Responsive fidelity is mandatory for phone, tablet, desktop, and intermediate widths.
- Current production site/main branch must not be modified by prototype work.

## Review standard
Before any production consideration, inspect the prototype as a human user at mobile, tablet, desktop, and narrow/intermediate widths and verify that no visual component is missing, clipped, overflowing, misaligned, or disproportionately scaled.
